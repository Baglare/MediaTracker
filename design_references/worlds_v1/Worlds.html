Tailwind-friendly Notes

Theming approach

  • Apply data-world="east|screen|arch" to <html> or the dashboard root. CSS variables under the selector cascade everywhere.
  • Add tailwind tokens via tailwind.config.ts extend.colors: world.primary, world.secondary, world.soft, world.line, world.ink — all var(--w-*).
  • Settings page sets data-world="neutral" on its layout to opt out of world tinting per the brief.
  • Persist the selected world to localStorage("mt:world"); hydrate on mount before paint to avoid flash.

Component impact

  • editApp shell stays. No structural changes.
  • new<WorldHero/> — replaces today's static Kütüphanem hero. Slots: glyph, eyebrow, title, sub, subgroup tabs.
  • editMediaCard — accent border + chip color from var(--w-primary). No prop changes.
  • editSeriesGroupCard — corner ornaments are ::before only; behavior identical.
  • editRightRail widgets — accent stripe / corner stamp via world data-attr.
  • new<WorldTransition/> — full-bleed macro animation on world change.

Animation budget

  • Macro (world change): one transition per change, 0.9–1.6s. Block input during; pre-render in compositor layer (will-change: transform, opacity).
  • Micro (hover, active subgroup): ≤200ms, transform/opacity only, respect prefers-reduced-motion: reduce.
  • No looping ambient motion — brief said "no constant loud motion".
  • Subgroup switch inside a world uses a soft 180ms crossfade; no macro replay.

Ship order

  • P0Token plumbing + data-world attribute + Settings opt-out.
  • P0WorldHero + subgroup tabs (static motifs, no anim yet).
  • P0Card/SeriesGroup/RightRail accent layer.
  • P1Macro transition component (katana / aperture / wax).
  • P1Empty/ghost state world treatment.
  • P2Per-subgroup micro-motifs (manga yin-yang spin, novel ink wash, film perforation scroll).

Implementation Notes

What to delegate

  • Wire useWorld() hook (context + localStorage) and route changes through it.
  • Generate Tailwind plugin that exposes bg-world-soft, text-world-primary, border-world-line, ring-world-glow mapped to CSS vars.
  • Refactor existing MediaCard/SeriesGroupCard to read accent from CSS vars (no prop drilling).
  • Add data-world to <html> via Next.js layout, with a no-flash inline script.

What to keep in design

  • Exact motif geometry (slash angle, aperture timing, wax seal scale curve).
  • Subgroup tab micro-animations — review with motion lead before shipping.
  • Empty/ghost state copy and glyph choice — needs editorial pass.
  • Theme contrast review for AA on dark surfaces — Doğu gold on bg-1 may need to step to --w-primary-strong.
