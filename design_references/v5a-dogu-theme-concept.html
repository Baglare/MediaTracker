V5A — Developer handoff

Doğu / Eastern theme. Component logic preserved; visual layer themed via tokens + a `[data-theme="dogu"]` scope.

Components touched

  • <ThemeTabs /> — new. Tümü / Doğu / Ekran / Kütüphane. Renders inside the existing `<Header />` row, replacing the section nav for theme-mode views.
  • <DoguSubTabs /> — new. Anime · Manga · Novel sub-pills. Conditionally rendered when active theme is dogu.
  • <DoguHero /> — new. Compact (180px) cinematic strip. Props: activeSub, counts.
  • <MediaCard /> — variant only. Same props/state. New visual via [data-theme="dogu"] .media-card.
  • <SeriesGroupCard /> — variant only. Adds <SeasonRow /> children for the expanded state.
  • <Badge /> — adds variant="dogu-gold" and variant="dogu-neutral".
  • <QuickSearchResult /> — new. Used by the existing Quick Search dropdown when a Doğu match is selected.
  • <ThemeProvider /> — sets document.documentElement.dataset.theme. Persists in localStorage.

V5A vs V5B — what ships when

V5A — visual + foundations SHIP NOW

  • Token layer: --dogu-* vars, [data-theme="dogu"] scope, ThemeProvider + persistence.
  • Header theme tabs (Tümü / Doğu / Ekran / Kütüphane).
  • Doğu sub-pills (Anime / Manga / Novel) with motif glyphs.
  • Compact DoguHero strip (single layout, kanji per sub).
  • MediaCard Doğu skin (corner brackets, gold rule, 印 seal, 3-stop progress).
  • Quick Search result Doğu badge.
  • Static micro-animations: corner reveal, progress fill, seal stamp.
  • Cormorant Garamond + Noto Serif JP loaded as Google Fonts (substitute, flagged).

V5B — motion + depth NEXT

  • SeriesGroup expanded view animations (chev rotate, season stagger).
  • Katana glint sweep on theme activation.
  • Sub-tab ink-draw transition.
  • Hero kanji breathe loop.
  • Quick Search ink-draw appearance.
  • Brand-supplied display + CJK fonts replace Google Fonts.
  • Two further themes scaffolded on the same token contract: Batı and Sayfa (placeholder names).
  • Doğu treatments for Stats grid, AI Danışman cards, Activity timeline.
Out of scope for both V5A and V5B: redesigning the app shell, replacing the routing model, changing the offline-first data layer, or touching the existing component logic. Doğu is purely a token + variant skin over the components you already ship.
